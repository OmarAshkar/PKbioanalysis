# Reverse predict concentration from response

Reverse predict concentration from response

## Usage

``` r
reverse_predict(fit, newdata, intercept)
```

## Arguments

- fit:

  lm object

- newdata:

  vector or data frame with response values

- intercept:

  logical. Whether the model has intercept or not

## Value

numeric. Estimated concentration
