# Install Python dependencies for PKbioanalysis

Install Python dependencies for PKbioanalysis

## Usage

``` r
install_py_dep(..., envname = "PKbioanalysis")
```

## Arguments

- ...:

  Additional arguments passed to reticulate::py_install

- envname:

  Name of the virtual environment to create/use. Default is
  "PKbioanalysis"

## Value

None
