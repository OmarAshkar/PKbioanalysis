# Plot Relationship Between Concentration and CV/SD

Plot Relationship Between Concentration and CV/SD

## Usage

``` r
plot_var_pattern(df, title = "")
```

## Arguments

- df:

  Data frame with columns: stdconc (standardized concentration), cv
  (coefficient of variation), sdev (standard deviation), Type (e.g.,
  "Estimated", "Observed")

- title:

  Plot title
